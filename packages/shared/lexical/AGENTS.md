# `@kobato/lexical`

The Kobato Lexical document model — the React-free storage format for post/page/comment bodies. Owner of: the Lexical storage schemas (`schema` — the full ARTICLE schema + `EMPTY_LEXICAL_EDITOR_STATE`; `comment-schema` — the restricted COMMENT schema + `EMPTY_COMMENT_EDITOR_STATE` + the `isCommentEditorStateBlank` submit gate; `node-whitelist`; `dialect` — compact↔full parse parity), the save pipeline (`walk`, `collect` — headings/image-storage-paths/music-player ids derived columns, heading slugs composed through inkling's `slugify` + `createHeadingIdTracker`; `artifacts`, `equivalence` — the artifact-blind fingerprint for the save no-op short-circuit), `projection-state` (feed artifact stripping + defensive host-card substitution), and `cards/` — the React-free host-card specs (`solution`, `two-column`, `music-player`, `kobato-image`, the `card-html` render helpers). `styles/cards.css` is a compile-only partial — a `@theme inline` token bridge plus `@source '../cards'`, no own Tailwind compile and no `dark` variant re-declaration (UI owns the variant) — composed by the app/demo surface entries and contract-pinned to UI tokens by the app's `tailwind-source-ownership.test.ts`.

- Allowed deps: `@kobato/inkling/headless` (the ONLY react-free surface — erased types + the slug composition), `@kobato/assets` (image srcset/kind), `@kobato/sanitize` (`isSafeUrl`), `@kobato/utils`. Never contracts, settings, cache, seo, or any product package in `src/`.
- Boundary: the Lexical runtime and generic editor kernel live in `@kobato/inkling`; the host-card assemblies (React class objects built from these specs) live in `@kobato/web/ui/admin/editor/cards`; the composer-mounted node-set contract lives in `packages/web/tests/contract/composer-nodes.ts`. Lexical owns only the storage model + specs — two class objects, one spec.
- Bans: no `SerializedEditorState` runtime import (erased `import type` only), no projection execution (the server's `infra/lexical` renders it).
- Tests: `tests/unit/` (umbrella `shared-unit` project — see `packages/shared/tests/AGENTS.md`).
