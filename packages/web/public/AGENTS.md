# Web-public conventions

`@kobato/web-public` (`packages/web/public/`) is the public-frontend leaf: the public chrome (header/footer/layout), the comment thread and comment composer, the post body projection and its hydration hooks, widgets, the music player, the friends grid, and the two cross-surface tiers below. It may import `@kobato/web-client` (the browser platform BELOW it), `@kobato/ui`, `@kobato/inkling` (barrel), and the shared leaves it declares (`@kobato/{utils,i18n,auth,catalog,settings,assets,lexical,sanitize,contracts}` — never `@kobato/seo`). It must NOT import `@kobato/web-admin` (the admin leaf reuses audited modules of THIS package as a long-term seam — the direction is admin → public, never the reverse; `apps/kobato/tests/arch/web-direction.test.ts` + the package DAG enforce this with no exceptions) and must NOT import `@kobato/server` or use Node-only APIs. The oRPC client is reached through `@kobato/web-client/api/client` and typed exclusively through `@kobato/api`.

## Structure

`src/ui/` is flat public modules plus two cross-surface subdirs (the former `ui/public/**` contents were lifted one level on the split):

- `chrome/` — public document chrome: `BaseLayout`, `Header`/`Footer`, `BrandLogo`, `ThemeToggle`, `UserMenu` (+ lazy twin), `ScrollTopButton`, `NavigationSplash`, `ChunkReloadOverlay`, `ErrorView`, `NotWordPressView`, `RumConsentBanner` (rendered post-mount by the root `App`, only while undecided, never for DNT/GPC visitors), `use-chrome-clock`.
- `comments/` — the public comment thread. Thread state is four contexts in `comments-context.ts` (Tree / Identity / ReplySlot / Actions) so leaf rows subscribe to slices. `CommentBodyEditor` wraps the inkling composer with the trimmed node set (`editor/comment-editor-nodes`: no headings, asides, tables, images, host cards, or math cards — code blocks stay; a ```math fence is the formula path), the `DEFAULT_TRANSFORMERS` subset in `editor/comment-markdown-transformers.ts`, the seed-time legacy downgrade in `editor/comment-legacy-math.ts`, `isEmojiEnabled={false}` / `codeEditor="plain"` so no emoji-mart/CodeMirror chunk loads here. Consumers mount through `LazyCommentBodyEditor` (composer, inkling island and `styles/inkling-comment-editor.css` ride a lazy chunk; the public post page stays editor-free); the always-visible reply form is interaction-gated, inline reply/edit forms pass `eager` + `focusOnMount`, both hover-prefetching via `warmCommentEditorChunks`. A PUBLIC document prefetches the active locale's Inkling label chunk (`@kobato/web-client/editor/inkling-labels::loadInklingLabels`) and mounts only after it resolves; focus activations hold the iOS viewport zoom lock (see `packages/web/client/AGENTS.md` → iOS auto-zoom). Comment bodies render the stored `content` HTML through `CommentContentHtml` with the narrower `'comment'` sanitize preset. Server and client first render both emit the placeholder shell (byte-stable hydration); the wrapper hands focus to the contenteditable after mount.
- `post/` — bodies render the saved `bodyHtml` projection: `DetailBodyChrome` sanitizes it with `sanitizeHtml(html, 'body')` into the `post-content` typeset container; five hydration hooks enhance the static markup (`useMediumZoom`, `useThumbhashHydration`, `useCodeCopyButtons`, `useMusicPlayers`, `useFootnotePreviews`, all beside the chrome). All five take `bodyHtml` as their re-scan key — the content div is reused across client navigations, so without it the previous article's enhancements leak onto detached nodes.
- `music-player/` — `MusicPlayerCard` hydrates onto `.aplayer[data-*]` mount points via `useMusicPlayers` (in `post/`); its SSR fallback parity is pinned by `tests/unit/ui/music-player/music-player.test.tsx` (see root AGENTS → hydration rule).
- `widgets/`, `friends/`, `webmentions/`, `Search.tsx`, `Sidebar.tsx`, `LikeActions.tsx` — public-only leaf modules. Use `<Image />` from `ui/widgets/Image` for transformed remote images.
- `shared/` — used by BOTH the public chrome and the admin shell (a long-term cross-surface tier): `notifications/` (the drawer opened from the admin sidebar AND the public user menu; `notification-meta.ts` owns kind/source → icon + `formatNotificationTime({ locale, timeZone, now })` — the consumer resolves the id with its own `t`), `auth/use-logout.ts`, `music/lrc.ts` (LRC lyric parser shared with the admin lyrics display). Modules here NEVER import admin modules — that direction would invert the tier.
- `lib/` — `LocaleSyncProvider` (the ROOT cross-tab loop mounted by `src/root.tsx`; a registered settings workspace flushes dirty cards then reloads once, every other document shows a localized alert with an explicit Reload — full contract in `packages/web/admin/src/ui/settings/AGENTS.md`) and `toast-api-error.ts` (the toast choreography admin uploads reuse).

## Styles

`src/styles/` owns the public-surface partials (never compiled alone): `public.css` scans the whole package `../ui` tree and owns the public zoom/comment-flash rules; `admin-subset.css` pins the precise per-module subset the admin surface renders (shared, lib, music-player, chrome, top-level comment modules, widgets, `Search.tsx`) as a long-term seam; `inkling-comment-editor.css` holds the comment canvas host rules (imported only by `CommentBodyEditor`, riding its lazy chunk). The exact `@source` sets are pinned by `apps/kobato/tests/arch/tailwind-source-ownership.test.ts`.

## Rules

- Imports use `@kobato/web-public/...` inside this package; production sources are browser-safe (no `node:*` value imports).
- Interface copy is a UI message id resolved through `useI18n()`; icons are named `lucide-react` imports; conditional classNames go through `cn()` from `@kobato/ui/lib/cn`; JS-driven animation only through the `@kobato/ui/components/lazy-motion` facade with constants from `@kobato/web-client/lib/motion`.
- Never import `shiki` here — highlighted code arrives pre-rendered (SSR-only).
- Tests live in `packages/web/public/tests/{unit,snaps}` (mirroring `src/ui/`), run by the umbrella `web-unit`/`web-snaps` projects rooted at `packages/web/tests` (see `packages/web/tests/AGENTS.md`).
