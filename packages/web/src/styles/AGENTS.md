# Web style conventions

`packages/web/src/styles/` owns Kobato-specific editor adapters and the product-component `@source` partials consumed by the app/demo surface compiles. Every file here scans only `packages/web`.

- `public.css` and `admin.css` are partials, not compilation entries: no `@import 'tailwindcss'`, no top-level cascade-layer order declaration, no UI reference — the consuming surface entries (`apps/kobato/src/styles/{public,admin}.css`, `apps/inkling-demo/styles/public.css`) run the single Tailwind compile and compose them via CSS `@import`. Each partial keeps its own `@source` and custom rules; components never import partials (`BaseLayout` carries no stylesheet import).
- `public.css` scans `ui/public` plus the two cross-surface tiers both app surfaces render — `ui/shared` (NotificationsDrawer opens from the admin sidebar AND the public user menu) and `ui/lib` (LocaleSyncProvider's root notice mounts on every document) — and owns public zoom/comment-flash rules. `admin.css` scans `ui/admin`, the same two cross-surface tiers, and the public modules admin deliberately renders (`ui/public/music-player`, `ui/public/chrome`, the comment editor surface under `ui/public/comments`, `ui/public/widgets`, `Search`), and owns admin zoom/scrollbar rules. A missing cross-surface scan silently drops that tier's utilities from the surface CSS, so each partial's exact `@source` set is pinned by the required-scan map in `apps/kobato/tests/arch/tailwind-source-ownership.test.ts`, which also keeps admin's public entries a precise per-module subset (never a blanket `ui/public` scan). Neither partial scans `client/` — the platform layer carries no product styles.
- The `dark` variant stays UI-owned: partials must not re-declare `@custom-variant`.
- `inkling-editor.css` is imported with Inkling's own `index.css` by `PageBodyEditor`; `inkling-comment-editor.css` follows the same composition in `CommentBodyEditor`. Web owns only unlayered host rules.
- The page canvas uses `zoom: 2/3`, token/spacing bridges, and host-card token restores. The comment canvas has no zoom because it breaks contenteditable IME painting.
- Inkling owns its own preflight, dark variant, layer, utilities, and source scan. Web never imports Inkling's sheet through another Tailwind compile and never scans Inkling sources.
- Contracts: `packages/web/tests/contract/editor-canvas-scope.test.ts`, `editor-host-card-tokens.test.ts`, and the app-level `tailwind-source-ownership.test.ts`.
